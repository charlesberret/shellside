A dual-surface site: the same content tree renders as a readable page,
a read-only console, and plaintext for machines. This file is
`src/content/index.md` — the page's own body. Add a directory and it
becomes a section; give a directory its own `index.md` and it gets a
landing page; prefix a name with a dot and only the console sees it.
