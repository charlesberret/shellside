# @shellside/edit-protocol

The `data-edit` grammar the editorial desk speaks: path parsing, field kinds,
allowlists, the typed preview-bridge contract (postMessage + CustomEvent
channels), and admin-preview URL helpers.

```js
import { parseContentPath, ADMIN_PREVIEW_PARAM } from "@shellside/edit-protocol";
```

Docs: `docs/LIVE_EDIT.md` at the repo root.
